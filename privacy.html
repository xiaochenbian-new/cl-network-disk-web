网兜（Wangdou）隐私政策

生效日期：2026年10月14日

本政策说明网兜（下称"本软件"）如何处理你的信息。开发者非常重视隐私：本软件的核心设计是你的网盘凭证与文件数据不经过开发者的任何服务器。

一、存储在本机的信息

1. 你登录的网盘账号凭证（Cookie、Token、密码等）仅保存在本机（%LOCALAPPDATA%\\Wangdou 目录），使用 Windows 系统凭据保护（DPAPI）加密存储，不会上传到开发者的服务器。

2. 应用设置、传输历史记录等同样仅保存在本机。卸载软件或删除上述目录即可彻底清除。

二、开发者能收到的信息

1. 设备标识：激活或验证 VIP 时，本软件向核销服务（license.wangdou.win，基于 Cloudflare）发送一个由本机主机名与用户名哈希生成的匿名设备 ID，用于激活码与设备的绑定校验。该 ID 不含姓名、手机号等个人身份信息，也无法反推出你的网盘账号。

2. 核销记录：激活码、套餐与设备绑定关系、时间戳，用于提供 VIP 服务。

3. 版本检查：检查更新时向核销服务 / GitHub 请求最新版本号。请求中不附带个人数据。

三、可选的云端备份（WebDAV / 网兜账号）

1. 如你启用 WebDAV 账号同步，备份内容（含网盘凭证）会先经 AES-256-GCM 端到端加密，再上传到你指定的 WebDAV 网盘（如坚果云、123 云盘）。

2. 加密密钥由你设置的备份密码派生，仅保存在本机；WebDAV 服务器与开发者均无法读取备份内容。请妥善保管备份密码，丢失后备份将无法解密。

3. 如你登录网兜账号并开启「云端备份」，网盘账号数据将以端到端加密形式上传到核销服务：加密密钥由你的登录密码在本机派生（PBKDF2），服务端只存储密文与派生盐，无法解密其内容。关闭备份后可随时删除云端密文。

4. 登录相关数据：邮箱、密码的单向哈希（PBKDF2-SHA256）、会话令牌的哈希。密码明文不上传、不存储。

四、与第三方的通信

1. 文件操作（浏览、上传、下载、分享）直接发生在你的电脑与对应网盘官方服务器之间，开发者不经手、不中转、不存储你的文件内容。

2. 更新安装包来自 GitHub Releases（xiaochenbian-new/wangdou-releases）。

3. 各第三方服务有自己的隐私政策，本政策不适用于它们。

五、信息的使用与共享

1. 上述信息仅用于提供与维护 VIP 激活服务、防止激活码滥用。

2. 开发者不会出售、出租你的个人信息；除法律法规要求或司法机关依法定程序要求外，不会向第三方提供。

六、未成年人

本软件及 VIP 服务面向普通用户，未成年人应在监护人指导下使用并在监护人同意后购买。

七、政策更新

政策更新后会在应用内提示。继续使用即视为接受更新后的内容。
