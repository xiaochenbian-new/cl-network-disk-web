登录网兜 Web

使用网兜账号（邮箱 + 密码）登录。登录状态将保持在本机，无需每次刷新重新登录。

    关于网兜 Web

    网兜 Web 是网兜桌面客户端的网页版：登录后可在线管理云端备份中的网盘账号，浏览、下载、播放文件。

    同账号的完整功能（虚拟盘映射、上传、跨盘同步等）请使用 Windows 客户端。
